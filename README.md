Тестовое задание на позицию Middle Unity developer

Версия Unity 2022.3.62f1 LTS

Управление:
- PC: Клавиатура и мышь
- Mobile: Джойстик слева - движение, кнопка справа - стрельба
- Переключение между схемами управление на кнопку справа сверху (Change Input Scheme)
- Кнопка открытия характеристик (Characteristics)

Детали реализации:
- Модульность реализована с помощью сервисов, в редакторе можно найти в таблице Assets>Settings>ServicesTable
- Локализация в виде затычки, может быть легко заменена другим сервисом в таблице
- UI реализован с упором на поддержку разных разрешений, код плохо расширяется, более гибкий вариант я реализовывал в другом задании: https://github.com/Dasthas/test_ui_screens
- Время выполнения: 12 часов

Используемые плагины:
- UniRx
- DoTween
- TextMeshPro
- VContainer
- Odin Inspector
- Cinemachine
